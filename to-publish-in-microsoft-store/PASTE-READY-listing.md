## Description
TidyUp watches your Downloads folder and quietly moves new files into folders you can read at a glance: Installers, Zip files, Pictures, Videos, Music, PDFs, Documents, Spreadsheets, Game files, 3D models, and any rule you add yourself.

Set it once, then forget it exists. It sits in the tray and does its job.

NOTHING IS EVER DELETED. TidyUp only moves files, and every move has a Put back button. Put one file back, or put everything from today back, in one click.

IT WAITS FOR DOWNLOADS TO FINISH. Pictures and documents move two minutes after they stop changing, installers and zips after five, so a file you are about to open does not vanish under you. Half-downloaded files are never touched.

IT KNOWS WHERE A DOWNLOAD CAME FROM. Windows records the website behind every browser download. "Files from moodle go to University" works with zero guessing.

ONLY NEW FILES, IF YOU WANT. On first run TidyUp tells you how many existing files match and lets you leave them alone.

RULES YOU CAN EDIT. Add file types, words in the name, or websites to any card. Change where it goes and how long it waits. Add your own rule. Every setting is a switch or a pill, nothing to type unless you want to.

TIDY FOLDERS. A category folder that stays empty for a week is removed, if you like.

LIGHT, DARK, OR FOLLOW WINDOWS. A small note at the bottom of the screen when something is filed, with Put back right on it.

No AI, no account, no internet. TidyUp has no network code at all: no analytics, no crash reports, no update checks. Your files never leave your computer.

Source-visible at github.com/nur-arpon/TidyUp.

## Certification notes (Submission options > Notes for certification)
TidyUp is a packaged Win32 (runFullTrust) desktop app built with Tauri v2. It needs full trust because it watches folders the user chose, moves files within them, shows a tray icon and a transparent toast window; there is no narrower capability for a desktop file watcher. It has no network code. To test: install, complete the three-step setup (accept Downloads, keep default categories, choose "Leave them, only tidy new files"), then download any PDF with a browser; two minutes after the download completes it moves to Downloads\PDFs and a toast appears with a Put back button. The tray icon (right-click) has Pause, Resume, Tidy now and Quit. Start with Windows uses the manifest's startupTask.
